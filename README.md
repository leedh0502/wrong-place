# Wrong Place

밤의 도시에서 살아남아 빠져나가야 하는 1인칭 공포 생존 게임입니다.

## 받기

[Releases](../../releases/latest)에서 `Wrong.Place.zip`을 받으세요.

## 실행

1. `Wrong.Place.zip`의 압축을 풉니다(풀면 약 6.7GB).
2. `Wrong Place` 폴더 안의 `Wrong Place.exe`를 실행합니다.
   - `game` 폴더는 게임 본체이니 옮기거나 지우지 마세요.

- 필요한 환경: Windows 10/11 64비트
- 조작키는 게임 안의 설정 화면에서 볼 수 있습니다.

## 게임

- 새 게임마다 시가지·읍·공단 세 맵 중 하나에서, 매번 다른 자리에서 시작합니다.
- 필요한 물건을 모아 도시를 빠져나가는 길(터널)을 지나면 끝납니다.
- 종이 지도(M)를 펴면 내 위치와 바라보는 방향이 화살표로 보입니다.
- 화면 중앙 하단의 막대는 지금 내가 내는 소리가 괴물에게 얼마나 멀리 들리는지 보여 줍니다.

## 마이크 (선택)

설정에서 마이크를 켜면 플레이어의 목소리 크기를 괴물들이 듣습니다.

- 게임을 켤 때 편하게 낸 '아~' 소리로 목소리 크기를 맞춥니다.
- 소리 크기만 재고, 녹음하거나 저장하지 않습니다.
