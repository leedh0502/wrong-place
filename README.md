# Wrong Place

도시에서 살아남고 탈출해야하는 1인칭 공포 생존 게임입니다.

## 받기

[Releases](../../releases/latest)에서 `Wrong.Place.zip`을 받으세요.

## 실행

1. `Wrong.Place.zip`의 압축을 풉니다(풀면 약 6.7GB).
2. `Wrong Place` 폴더 안의 `Wrong Place.exe`를 실행합니다.
   - `game` 폴더는 게임 본체이니 옮기거나 지우지 마세요.

- 필요한 환경: Windows 10/11 64비트
- 조작키는 게임 안의 설정 화면에서 볼 수 있습니다.

## 마이크

마이크를 켜면 플레이어의 목소리 크기를 괴물들이 듣습니다.

- 게임을 켤 때 편하게 낸 '아~' 소리로 목소리 크기, 기준을 맞춥니다.
- 소리는 게임 플레이용으로만 사용되며, 녹음하거나 저장되지 않습니다.

## 출처

- 소리: Freesound 등의 CC0 / CC BY 소리를 사용했으며, 출처는 게임 설정의 크레딧에 있습니다.
- 3D 모델·텍스처: Poly Haven(CC0) 등
- 글꼴: 나눔손글씨 펜(SIL Open Font License 1.1). 라이선스 전문은 `game\LICENSES`에 있습니다.
