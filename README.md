## 소개

**Wrong Place**는 낯설고 뒤틀린 도시에 홀로 떨어져, 살아남아서 빠져나가야 하는 1인칭 공포 생존 게임입니다.

- 각종 이상현상과 괴물들이 존재하는 도시에서 살아남고, 탈출해야합니다.
- 물, 음식, 면역, 상처를 관리하며 버텨야 합니다.

## 게임 방법

1. 집, 가게, 사무실, 학교 등등을 뒤져 **탈출에 필요한 물건들**을 모읍니다. 무엇이 필요한지는 J를 눌러서 볼 수 있습니다.
2. 잠긴 문은 도구로 부수고 들어갈 수 있습니다. 도구는 쓸수록 닳아서 결국 부서집니다.
3. 밤에는 손전등이 중요합니다. 손전등없이는 앞이 거의 보이지 않을것이며 플레이어의 낡은 손전등은 건전지를 오래 사용할 수 없습니다. 
4. 필요한 물건을 다 모아서 도시를 빠져나가면 클리어입니다.
5. 제한시간은 없지만 도시에 너무 오래남지 않는것을 권장드립니다.

| Esc | 일시정지 |

## 받기와 실행

1. 아래 `Wrong.Place.zip`을 받아 압축을 풉니다(풀면 약 7.2GB).
2. `Wrong Place` 폴더 안의 `Wrong Place.exe`를 실행합니다.
   - `game` 폴더는 게임 본체이니 옮기거나 지우지 마세요.

- 필요한 환경: Windows 10/11 64비트
- 버전: 0.1.75 (메뉴 화면 오른쪽 아래에 표시됩니다)

- 언어는 현재 한국어만 지원하고 있습니다.
- 멀티플레이 지원은 구상중에 있으며 언젠가는 제공될 사항입니다.


이 게임은 코드작성 및 아트워크부문에서 Ai를 사용하였음을 명시합니다.
